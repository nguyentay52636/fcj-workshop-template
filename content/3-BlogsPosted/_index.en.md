This section presents a summary of technical blogs published on the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj):

### [Blog 1 - What Should an AI Engineer Prioritize Learning in AWS Study Group?](3.1-Blog1/)

This blog shares practical perspectives from an AI Engineer's career path on AWS. It analyzes essential foundational infrastructure services (Amazon S3, IAM, EC2) alongside specialized AI/ML services (Amazon SageMaker, Bedrock, Rekognition) to help learners optimize their time and prepare for production work.

### [Blog 2 - What Should a Data Engineer Prioritize Learning in AWS Study Group?](3.2-Blog2/)

This post outlines an optimized learning roadmap for Data Engineers on AWS. It covers key services across the cloud data processing ecosystem, including Data Lake Architecture (S3), ETL Processing (AWS Glue), Data Warehousing (Amazon Redshift), Real-time Streaming (Amazon Kinesis/MSK), and Ad-hoc Analytics (Amazon Athena).

### [Blog 3 - From Theory to Execution: The Data Engineering Challenge in a Real-World GenAI/RAG Project](3.3-Blog3/)

This article deep-dives into a real-world GenAI/RAG system architecture, demonstrating that 80% of system stability and performance relies on Data Engineering. Key pieces: Event-Driven Ingestion (S3 Event + SQS), unstructured ETL (Textract OCR + DynamoDB vectors), **exact-match cache** on ElastiCache (not a true semantic cache), a RAGAS + EventBridge evaluation pipeline in **Partial** status, and Data Observability (CloudWatch + SNS).
